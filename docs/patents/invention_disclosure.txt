1. TITLE OF INVENTION: Advanced Pothole Detection and Automated Filling using Raspberry Pi and Deep
Learning Approaches
2. PLEASE ATTACH A DESCRIPTION OF THE INVENTION (refer to instructions) The proposed invention is a smart
and automated system for pothole detection and filling. It integrates Raspberry Pi, deep learning models, cloud computing,
GPS-based geolocation, and servo motor-based actuation to address the issues of road damage efficiently. The system
detects potholes in real-time, estimates their dimensions, and stores relevant data in the cloud. It then uses servo motors to
automatically dispense appropriate repair material into the detected potholes, providing a complete end-to-end solution for
road maintenance.
i. General Purpose
The general purpose of this invention is to develop an IoT-enabled, automated road maintenance system that can detect
potholes, estimate the volume of damage, and initiate repair by dispensing filling material. The aim is to ensure accurate,
timely, and cost-effective maintenance of roads while reducing the dependency on manual inspection and repair methods.
ii. Technical Description
Hardware Components:
● Raspberry Pi 3 serves as the processing unit.
● A camera module captures real-time road images.
● A GPS module records the location of each detected pothole.
● Servo motors are used to dispense the repair material at the pothole site.
Software Components and Technologies:
● YOLOv9 is employed for high-speed, accurate object detection and segmentation.
● A pre-labeled dataset from Roboflow is used to train the model.
● Monocular depth estimation is applied to calculate the depth of potholes.
● Google Cloud Storage stores the captured images and metadata.
● Streamlit is used for the dashboard interface.
Workflow:
1. The Raspberry Pi captures road images.
2. YOLOv9 detects and classifies potholes in the images.
3. GPS module tags the image with location data.
4. Depth estimation algorithms calculate the pothole volume.
5. Data, including images and metadata, is uploaded to the cloud.
6. Based on the processed data, servo motors on municipal vehicles are triggered to dispense filling material
automatically.
iii. Advantages and Improvements Over Existing Methods
● The system offers full automation, from detection to repair.
● It ensures high accuracy in detection and volume estimation through the use of deep learning and image processing.
● It is cost-effective due to the use of low-cost components like Raspberry Pi and servo motors.
● The integration of GPS and cloud services allows for centralized monitoring and data-driven decision-making.
● Real-time data collection and analysis enable timely and efficient road maintenance.
iv. Potential Commercial Applications
● Integration into smart city infrastructure for automated road monitoring and maintenance.
● Deployment on municipal or contractor vehicles for real-time pothole detection and repair.
● Use by government agencies and road transport departments for planning and executing maintenance operations.
● Application in developing countries where affordable and scalable solutions are required for road infrastructure
management.
